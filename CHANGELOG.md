## v1.4.1 — Initial public release

- Add movies and TV series to a Nuvio library from IMDb, Letterboxd, Rotten Tomatoes, and TMDB.
- Remove saved titles by clicking the same button again.
- Show whether a title is already in the selected Nuvio profile, with loading, success, and error states.
- Switch between Nuvio profiles from the button menu and remember the selected profile.
- Match each button to the style and placement of its host site.
- Use the Nuvio icon in the extension and site buttons.
- Use the existing Nuvio session for authenticated library changes, without entering credentials on the title sites.
- Match titles by IMDb ID, TMDB ID, or a reliable catalog result; avoid adding uncertain matches.
